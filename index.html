Ferramentas CFSA

Tudo roda aqui no navegador. Nenhum arquivo é enviado pra servidor nenhum.

Gerador da base de alunos →

Lê o .xls que o sistema exporta e devolve o const BASE_ALUNOS pronto pra colar no Base.gs.

Gerador de usuários do hotspot →

Lê o mesmo .xls e monta o script do MikroTik: cada aluno vira um usuário com a matrícula como login e senha.

Limpa Link →

Tira os parâmetros de rastreamento de um link de qualquer loja ou site e devolve o endereço curto.

Os dois geradores precisam do arquivo .xls exportado pelo sistema, do jeito que ele sai.
